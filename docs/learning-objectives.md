# Learning Objectives

- Use modern Vanilla JavaScript to respond to events and update a web interface.
- Split application responsibilities into ES Modules with explicit imports and exports.
- Create, read, update, and delete related records while keeping the interface synchronized.
- Persist and restore JSON data with browser localStorage, including initialization and error handling.
- Validate user input and enforce role rules in business logic as well as in the interface.
- Use arrays, objects, maps, and array methods to manage relationships and calculate averages.
- Write automated tests with the Node.js built-in test runner.
- Build responsive pages with HTML5, CSS3, and Bootstrap 5.
- Use Git commits to record meaningful implementation stages and GitHub Actions to run checks.
